# NotMonk — Brave eklentisi

Yeni sekmeyi sade bir öğrenme takip panosuna dönüştürür. Veriler yalnızca tarayıcının yerel eklenti depolamasında tutulur.

## Brave'e kurulum

1. Brave adres çubuğuna `brave://extensions` yaz.
2. Sağ üstten **Geliştirici modu**nu aç.
3. **Paketlenmemiş öğe yükle** düğmesine bas.
4. Bu klasörü seç: `learnmap-extension`
5. Yeni bir sekme aç.

Eklenti mağazasına yüklenmediği için klasörü silme veya taşıma; Brave dosyalara buradan erişir.
